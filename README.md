# Expediente #001 — Ladrona de corazones ♡

Página estática romántica estilo cartel de SE BUSCA, preparada para GitHub Pages.

Archivos: index.html (portada), carta.html (carta), style.css (diseño), script.js (animaciones), sospechosa.png (foto).

Para publicar: sube todos los archivos directamente a la raíz de `main`, luego Settings → Pages → Deploy from a branch → main → /(root).

Para editar la carta, cambia los párrafos dentro de `.letter-body` en `carta.html`. Puedes agregar o quitar párrafos y la tarjeta se adapta automáticamente.
